\doctitle{Functional and data-quality tests}

The results below were captured on 21 November 2026. Eight deterministic tests exercise acquisition, validation, archiving and load control with synthetic fixtures. A separate live run checks real source messages and storage. The environment used Python 3.12.10 and Docker Compose v2.39.1.
