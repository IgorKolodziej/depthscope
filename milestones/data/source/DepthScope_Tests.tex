\doctitle{Functional and data-quality tests}

Nine deterministic tests exercise acquisition, validation, archiving, replay and load control with synthetic fixtures. A Compose run checks real source messages, storage and historical reprocessing. The environment used Python 3.12.10 and Docker Compose v2.39.1.

Other levels keep their quantities and order. & PASS. The resulting asks are $(1000.5,0.25)$ and $(1001.01,20)$.\\\addlinespace
